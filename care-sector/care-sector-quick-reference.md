# Care-sector quick reference

## If the issue is minor
- welfare meeting
- supervision
- coaching
- review date

## If the issue is uncertain
- fact-finding
- gather records
- decide whether formal action is needed

## If safety is affected
- assess safeguarding immediately
- consider suspension only if needed
- investigate promptly
- involve reporting obligations where necessary

## If formal action is needed
- written notice
- disciplinary meeting
- outcome letter
- appeal
