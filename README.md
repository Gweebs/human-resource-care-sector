# HR disciplinary process research pack

## Purpose
A structured research pack on the disciplinary process and best practice in the UK workplace context, from welfare meeting and matters of concern through warnings and termination.

## Scope
- welfare meeting / informal concern stage
- matters of concern / fact-finding
- formal disciplinary process
- investigation and suspension
- written warnings and final warnings
- appeal
- termination / dismissal
- best practice and procedural fairness
- UK statutory and Acas-aligned guidance

## Intended use
For HR reference, policy drafting, manager training, and app/content development.

## Geographic framing
This pack is written primarily for the UK employment context, with Acas as the main procedural benchmark.

## Care-sector note
This pack is especially useful for care homes, domiciliary care, and other regulated care settings where safeguarding and documentation matter.

## Care-sector integration
Care-sector material is merged into the main pack and supported by `care-sector/care-sector-unified.md`.

## Directory structure

| Directory | Use |
|---|---|
| `process/` | Core disciplinary process, decision tree, checklist, glossary, and UK framework |
| `care-sector/` | Care-specific guidance, manager notes, examples, safeguarding and investigation prompts |
| `handbook/` | Staff handbook alignment, case examples, and comparison notes |
| `templates/` | Policy wording and formal disciplinary template |
| `figma/` | Figma-ready process guide |
| `sources/` | Source notes for ACAS, GOV.UK, CIPD, nidirect, and Skills for Care |
| `skills/` | Reusable Codex skill for care-sector HR disciplinary drafting |
